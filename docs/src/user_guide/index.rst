User Guide
==========

pyb2d3 exposes the complete public API of `Box2D <https://box2d.org>`_ (v3.2) to Python.
Box2D itself is documented at `box2d.org/documentation <https://box2d.org/documentation/>`_;
this guide shows how its concepts look in Python.

All examples in this guide are tested: they live in ``docs/snippets`` and are executed by
``tests/test_docs.py``.
